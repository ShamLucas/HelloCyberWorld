## 📊 État du projet aujourd'hui

### 🛠️ Infra & DevOps (✅ Fondation solide)

**Ce qui marche :**
- Vagrant VM locale (dev, 192.168.56.10) avec Ansible
- Ansible structuré avec rôles modulaires (nginx, certbot, markdown-site, common, hp-envy, pi-hardware)
- Inventaire multi-cibles (dev, raspberrypi, hp_envy)
- Deux environnements de production prêts:
  - Raspberry Pi 4 (192.168.1.190) — original, prêt à redémarrer si HP en panne
  - HP Envy Debian (192.168.1.139) — nouveau, plus puissant (i7, 11Go RAM, GPU dédié)
- Gestion automatique des certificats Let's Encrypt via Certbot
- Nginx avec vhosts statiques et configuration automatique

**Points maitrisés :**
- Déploiement Ansible: SSH par clé, sudo elevation, rôles réutilisables
- Gestion de configuration par groupe_vars (dev/raspberrypi/hp_envy)
- Dépannage réseau et service (diagnostique rapid, reconfiguration sans downtime)
- Automatisation: anti-patterns (ex: Apache conflict sur port 80) détectés et automatisés
- Veille laptop: masquage systemd des sleep targets

**À améliorer pour la robustesse :**
- Post-deploy health checks (assert ports 80/443, certbot --dry-run, curl local)
- Monitoring / alerting minimal
- Backup stratégie (actuellement: manuel ad-hoc)
- Documentation post-déploiement unifiée
